### DSD vs PWM Implementation (Codification)

This section describes how the audio output is encoded starting from the digital core, comparing DSD (PDM) and PWM implementations.

---

## PDM (Pulse Density Modulation)

- Represents signal amplitude by the density of logic ones in a 1-bit digital stream.
- The analog signal is recovered by low-pass filtering.

---

## DSD (Digital Stream Direct)

- A specific form of PDM generated using a delta-sigma modulator.
- Shapes quantization noise toward high frequencies.

- **DSD** → [`DSD`](pcm_to_dsd.v)

---

## PWM (Pulse Width Modulation)

- Represents amplitude through the duty cycle of a periodic waveform.
- Although it is not strictly PDM, it is treated as an alternative 1-bit output encoding.

- **PWM** → [`PWM`](pwm_audio_out.v)

---

## Input from Core

- **Signed 16-bit number**
- Represents a PCM audio sample
- Generated by the audio core (FM synth or zCode sine)
- Sample rate in the audio range (≈ 48 kHz)
- This value must be adapted to a format suitable for direct FPGA pin output.

- **WAVE** → [`wavegen`](../core/wavegen.sv)

---

## Two "Bars" (Parallel Output Paths)

### Bar 1: PCM → DSD

- Uses a delta-sigma modulator
- PCM samples are stored in registers and processed by integrator registers
- Output is a 1-bit stream where:
  - Higher density of 1s represents positive amplitude
  - Higher density of 0s represents negative amplitude
- **Requirements:**
  - High bit rate (MHz range)
  - Simple RC low-pass filter
- **Priority:** Audio quality and noise shaping

### Bar 2: PCM → PWM

- Uses a counter and comparator
- The PCM sample is stored in a register
- The stored value sets the PWM duty cycle
- Output is a periodic waveform whose average value represents amplitude
- **Priority:** Simplicity and ease of implementation

---

## Registers

Registers are the key mechanism used in both bars to:

- Hold the current PCM sample
- Maintain internal state across clock cycles
- Implement time-based modulation

They form the interface between:

- Audio generation logic
- Output encoding logic

---

### DMA

A simple direct memory access that acts as a register sink , stores the most recent audio sample and it is used for development, testing and verification

- **DMA** → [`DMA`](dma_stub.v)

---

## Summary

- The audio core outputs signed 16-bit PCM samples
- Output DIR encodes these samples into 1-bit digital signals
- Two register-based encoding strategies are supported:
  - **DSD (PDM)** for higher audio fidelity
  - **PWM** for simplicity and rapid prototyping
- The use of registers ensures a clean and modular separation between the core and the physical output stage
